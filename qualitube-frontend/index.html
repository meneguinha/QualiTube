Guia do Pesquisador

O YouTube disponibiliza gratuitamente 10.000 cotas diárias para desenvolvedores em sua API de extração de dados. No entanto, as diretrizes do YouTube me proíbem de simplesmente pegar a sua chave de API para que as pessoas sejam consideradas usuários. Por isso, a única forma permitida de ter sua cota de acesso dedicada é rodando o aplicativo localmente no seu computador.

Mas a boa notícia é que qualquer pessoa pode ser um desenvolvedor hoje sem saber programar nenhuma linha de código! Com o auxílio de inteligência artificial, você pode rodar o app no seu PC com sua própria chave e ter cota ilimitada e controle total para customizar o app.

Passo a Passo para Ter Mais Cota e Autonomia

Fazer um "fork" significa criar uma cópia idêntica do código original deste projeto sob a sua própria conta do GitHub. Isso permite que você faça alterações e rode o projeto de forma independente e segura.

  1. Acesse o GitHub e crie uma conta gratuita caso não possua.
  2. Visite o repositório do QualiTube no GitHub .
  3. Clique no botão Fork no canto superior direito da página do repositório para criar a sua cópia.
  4. Na página do seu fork, clique no botão verde Code e escolha a opção Download ZIP (ou use o Git para clonar se preferir). Extraia o arquivo baixado para uma pasta no seu computador.

O Antigravity 2.0 é um assistente inteligente de programação em linguagem natural. Ele permite que você converse com o código-fonte do seu projeto para realizar ajustes e rodar comandos.

  • Acesse a página oficial e baixe o Antigravity 2.0 para instalá-lo no seu computador.
  • Você poderá orientar o software em linguagem natural (português) a fazer o que você quiser no código, sem precisar escrever sintaxes complexas.

O Google Cloud Console é a plataforma onde desenvolvedores solicitam acesso às APIs do Google. A ativação e o uso da API do YouTube são totalmente gratuitos para o limite diário padrão.

  1. Acesse o Google Cloud Console e faça login com sua conta do Google.
  2. Crie um novo projeto clicando no seletor de projetos no menu superior e escolhendo "Novo Projeto" (ex: QualiTube).
  3. No painel do projeto, vá na barra de pesquisa superior, busque por YouTube Data API v3 e clique em Ativar. Para referência, você pode acessar a documentação oficial: Instruções do Google para Chave de API do YouTube .
  4. No menu lateral esquerdo, acesse APIs e Serviços > Credenciais.
  5. Clique em + Criar Credenciais no topo e escolha Chave de API. Uma chave será gerada (um texto longo). Copie essa chave e salve em local seguro.

Agora que você tem o código-fonte no seu PC e o assistente instalado, vamos conectá-los.

  1. Abra o aplicativo Antigravity 2.0 no seu PC.
  2. Selecione a opção de abrir uma pasta de projeto existente e escolha a pasta com os arquivos do QualiTube que você extraiu no Passo I.

No chat do Antigravity 2.0, escreva o seguinte prompt em português para que ele ensine você e configure tudo de forma guiada:

Quero rodar localmente no meu PC com minha chave de API do Youtube. Não sou programador. Me oriente no passo a passo de como fazer.

Pronto! Com o app rodando localmente no seu computador e com o auxílio do Antigravity 2.0, você pode criar as funcionalidades personalizadas que desejar para sua pesquisa acadêmica.

Basta pedir para o assistente em português para fazer alterações estéticas, novos filtros de dados ou novos formatos de relatórios. O controle é todo seu!

Atenção com a segurança de sua chave de API!

Sempre que você for orientar a IA a fazer alterações ou novas funcionalidades, lembre-se de nunca expor ou salvar sua chave de API diretamente nos arquivos de código-fonte do aplicativo.

Esse cuidado é essencial caso você decida colocar a ferramenta online (hospedá-la na internet ou compartilhar o código publicamente no GitHub). Chaves salvas diretamente nos arquivos podem ser expostas publicamente, permitindo que terceiros consumam sua cota de acesso.
